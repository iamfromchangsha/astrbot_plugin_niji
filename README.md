# 📖 Niji Diary Logger

自动将你与 AI 的完整对话记录（用户消息 + AI 回复）每日同步至 [你的日记](https://nijiweb.cn) 网站，打造属于你的私人 AI 对话存档。

## ✨ 核心功能

- **自动同步**：绑定一次，永久自动备份，无需手动操作
- **数据安全**：仅保存文本内容，不上传图片/视频等媒体文件
- **多用户支持**：支持多用户独立记录，互不干扰
- **智能整合**：每日对话自动整合为单篇日记，保持聊天上下文
- **防覆盖机制**：新对话会追加到现有日记末尾，避免数据丢失

## 📦 版本要求

- **AstrBot ≥ v4.9.2**  
  （必须 ≥ 4.9.2，因使用了 `get_all_kv_keys()` API）
- **Python ≥ 3.8**
- 网络可访问 `https://nijiweb.cn`

## ⚙️ 安装方法

### 方法一：直接安装
1. 将本插件文件夹放入 AstrBot 的插件目录：
   ```
   astrbot/plugins/niji/
   ```

2. 确保目录结构如下：
   ```
   niji/
   ├── main.py
   ├── requirements.txt
   ├── metadata.yaml
   └── readme.md
   ```

3. 重启 AstrBot，插件将自动加载并安装依赖。

## 🔑 使用步骤

### 1. 绑定账号

在任意支持的平台（如 QQ、微信、Telegram 等）向 Bot 发送指令：

```
/login 你的邮箱 你的密码
```

**示例：**
```
/login user@example.com mypassword123
```

- 若返回 `✅ 绑定成功！...`，表示已启用自动同步
- 若返回 `❌ 绑定失败...`，请检查账号密码是否正确

> 🔐 安全说明：密码仅用于登录获取 token，不会被存储。token 会加密保存在本地 KV 中。

### 2. 开始聊天

绑定后，你与 AI 的所有对话（包括后续提问和 AI 回答）都会被自动记录。

### 3. 自动上传

- 插件会在 **每天北京时间 23:50** 自动将当日完整对话上传至 [你的日记](https://nijiweb.cn)
- 日记标题格式：`AI对话记录 - YYYY-MM-DD`
- 如果当天已有日记，新对话会**追加到末尾**（用 `---` 分隔），避免覆盖

### 4. 解绑账号（可选）

如需解绑账号，发送指令：

```
/logout
```

## 📝 注意事项

- **仅记录文本**：图片、语音、表情包等非文本消息会被忽略（显示为 `[无文本内容]`）
- **内存缓存**：对话记录暂存于内存，插件重启会丢失未上传的数据（建议避免在 23:50 前频繁重启）
- **上传失败处理**：若网络异常导致上传失败，数据会保留并在次日重试
- **多设备使用**：如果在多个平台使用同一个"你的日记"账号，建议只在一个平台绑定，避免重复记录

## ❓ 常见问题

### Q：为什么日记日期和聊天日期不一致？
A：本插件在 **每天北京时间 23:50** 上传，确保日记日期与聊天日期一致。

### Q：能手动触发上传吗？
A：目前不支持手动触发，所有上传均为自动执行，每日一次。

### Q：如何查看上传的对话记录？
A：登录 [你的日记](https://nijiweb.cn) 网站，在日记列表中查看标题为 `AI对话记录 - YYYY-MM-DD` 的条目。

### Q：绑定失败怎么办？
A：请检查：
1. 邮箱和密码是否正确
2. 网络是否可以访问 `https://nijiweb.cn`
3. AstrBot 版本是否 ≥ v4.9.2
