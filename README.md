# 📖 Niji Diary Logger

自动将你与 AI 的完整对话记录（用户消息 + AI 回复）每日同步至 [你的日记](https://nijiweb.cn) 网站，打造属于你的私人 AI 对话存档。

> ✨ 无需手动操作，绑定一次，永久自动备份  
> 🔒 仅保存文本内容，不上传图片/视频等媒体  
> 👥 支持多用户独立记录，互不干扰


## 📦 版本要求

- **AstrBot ≥ v4.9.2**  
  （必须 ≥ 4.9.2，因使用了 `get_all_kv_keys()` API）
- **Python ≥ 3.8**
- 网络可访问 `https://nijiweb.cn`

---

## ⚙️ 安装方法

1. 将本插件文件夹（包含 `main.py` 和 `requirements.txt`）放入 AstrBot 的插件目录：
   ```
   astrbot/plugins/niji_diary_logger/
   ```

2. 确保目录结构如下：
   ```
   niji_diary_logger/
   ├── main.py
   └── requirements.txt
   ```

3. 重启 AstrBot，插件将自动加载并安装依赖。

---

## 🔑 使用步骤

### 1. 绑定你的“你的日记”账号

在任意支持的平台（如 QQ、微信、Telegram 等）向 Bot 发送指令：

```
/login 你的邮箱 你的密码
```

✅ 示例：
```
/login user@example.com mypassword123
```

- 若返回 `✅ 绑定成功！...`，表示已启用自动同步。
- 若返回 `❌ 绑定失败...`，请检查账号密码是否正确。

> 🔐 密码仅用于登录获取 token，不会被存储。token 会加密保存在本地 KV 中。

### 2. 开始正常聊天

绑定后，你与 AI 的**所有对话**（包括后续提问和 AI 回答）都会被自动记录。

### 3. 每日自动上传

- 插件会在 **每天北京时间 23:50** 自动将当日完整对话上传至 [你的日记](https://nijiweb.cn)。
- 日记标题格式：`AI对话记录 - YYYY-MM-DD`
- 如果当天已有日记，新对话会**追加到末尾**（用 `---` 分隔），避免覆盖。

### 4. 解绑账号（可选）

如需解绑账号，发送指令：

```
/logout
```

---

## 📝 注意事项

- **仅记录文本**：图片、语音、表情包等非文本消息会被忽略（显示为 `[无文本内容]`）。
- **内存缓存**：对话记录暂存于内存，**插件重启会丢失未上传的数据**（建议避免在 23:50 前频繁重启）。
- **上传失败重试**：若网络异常导致上传失败，数据会保留并在次日重试。
- **多设备同账号**：如果你在多个平台使用同一个“你的日记”账号，建议只在一个平台绑定，避免重复记录。

## ❓ 常见问题

### Q：为什么日记日期和聊天日期不一致？
A：旧版本在 00:00 上传会导致错位。本插件已在 **23:50 上传**，确保日记日期 = 聊天日期。

### Q：能手动触发上传吗？
A：目前不支持。所有上传均为自动，每日一次。

### Q：如何解绑？
A：发送 `/logout` 指令即可解绑账号。
